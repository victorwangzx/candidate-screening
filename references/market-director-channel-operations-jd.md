# 市场总监 / 渠道运营负责人岗位卡

这是面向幼儿园及儿童消费渠道的示例岗位卡，不代表所有市场总监岗位。用户提供的JD及已确认期待优先。以下年限、团队规模和经营范围需由用户采纳后才作为硬性门槛；其他市场岗位只选相关维度，不强制要求幼儿园经验。

## 写入面试记录格式

- 追加候选人到“市场总监面试记录”时，候选人主标题使用 H1，并在姓名后用括号标注 AI 评分，例如：`# 31 张三（AI评分：8/10）`。
- AI 评分需与正文“整体适配度”中的数字保持一致；证据不足不宜打分时，写作 `AI评分：待定`。

## 岗位定位

面向幼儿园阶段消费者生态，寻找能够把儿童业务做成可规模化复制经营体系的增长型经营人才。该岗位不是传统品牌市场岗位，核心是渠道、加盟、区域运营、增长、地推和团队建设。

## 核心职责

1. 搭建全国渠道体系：幼儿园、母婴、城市代理、加盟、地推、异业合作及区域合作伙伴；形成招商模型、渠道政策、代理商考核与激励机制。
2. 对区域经营结果负责：招商、转化、GMV、用户增长、留存、复购、区域活跃度；推动单点经营向标准化、可复制的全国扩张演进。
3. 搭建并管理区域经理、渠道经理、城市 BD、地推与加盟运营团队；建立战略规划、SOP、培训、绩效和组织效率机制。
4. 整合幼儿园、母婴、儿童消费、地方代理、商场及区域教育资源，形成合作网络。
5. 建立数据化经营体系：渠道 ROI、城市模型、招商转化率、获客成本、区域经营效率与人效模型。
6. 需要对幼儿园有真实认知，能理解园长的经营压力、采购顾虑、招生诉求、教师使用负担和家长期待，从而帮助产品在园所更好落地，并把一线反馈转化为新的产品需求。

## 必须项

- 5 年以上渠道、市场或运营管理经验。
- 管理过 20 人以上团队。
- 有全国渠道或多区域经营经验。
- 能说明自己在渠道搭建、区域冷启动、团队复制、标准化运营中的实际职责与结果。
- 能以经营指标而非单一活动或传播指标复盘业务。
- 对幼儿园场景和园长视角有基本认知，能讲清园所为什么买、谁使用、如何持续用、如何形成招生/口碑/续费价值。

## 优先项

- 加盟体系、城市代理或连锁经营经验。
- 儿童教育、母婴、奶粉、儿童食品、儿童玩具、儿童智能硬件或连锁加盟行业经验。
- 幼儿园、早教、母婴渠道或儿童消费渠道资源。
- 从样板城市/样板客户到跨区域复制的完整经历。

## 关键评估维度

| 维度 | 重点验证 |
|---|---|
| 渠道与加盟 | 渠道结构、代理商分层、政策、准入、激励与淘汰机制 |
| 区域经营 | 城市/区域 P&L 或核心经营指标、冷启动和增长停滞处理 |
| 规模化复制 | SOP、培训、城市模型、中后台支持、管理半径与复制结果 |
| 团队管理 | 团队规模、组织设计、干部培养、绩效与激励 |
| 幼儿园认知与园长视角 | 是否理解园长的经营目标、招生压力、预算来源、采购顾虑、教师使用负担、家长期待及园所内真实落地路径 |
| 儿童行业与场景 | 对幼儿园、母婴、儿童消费渠道及园所决策链的理解 |
| 数据化经营 | ROI、转化、CAC、留存、复购、回款、库存/人效等指标使用能力 |
| 早期业务适配 | 能否亲自拿下样板客户、在资源有限时验证模型并迭代 |
| 产品反馈与需求转化 | 能否从园长、教师、家长和交付现场提炼产品改进需求，推动产研迭代，而不只是完成销售签约 |

## 高风险信号

- 经验主要是品牌传播、活动或内容投放，缺少渠道/经营结果。
- 只谈“招商”不谈代理商运营、动销、交付、回款和退出机制。
- 无法讲清个人职责边界、关键决策及结果指标的统计口径。
- 只有成熟平台资源，缺少从 0 到 1 冷启动或资源受限场景的实绩。
- 缺少幼儿园 ToB 决策链、课程交付、教师使用和续费/复购的理解。
- 只会把产品卖给园所，但无法讲清园长为什么愿意持续使用、教师如何不增加负担、家长如何感知价值，也无法把园所反馈沉淀为产品需求。

## 建议面试题

1. 请讲一个你亲自负责的渠道或加盟项目：目标、渠道结构、你的职责、关键决策、结果与复盘口径分别是什么？
2. 你如何选择、分层、激励和淘汰代理商/加盟商？请给出一个真实案例。
3. 如果从 10 家样板园做到 50 家园所，你会如何拆直营、代理、幼儿园集团和母婴渠道的分工与节奏？
4. 幼儿园采购“AI 美术课程 + 智能硬件”时，园长、投资人、教师和家长分别关心什么？如何设计成交与交付闭环？
5. 如果一个区域增长停滞，你会先看哪些数据，如何定位问题并在 90 天内验证改进？
6. 请举一个团队或城市模型被复制的案例：哪些 SOP、培训、数据机制保证复制没有走样？
7. 如果一位园长担心“买了以后老师不用、家长无感、招生没帮助”，你会如何回应并设计落地方案？
8. 请举例说明你如何从客户一线反馈中提炼产品需求，并推动产品、教研或交付团队做出迭代。
