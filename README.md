# Candidate Screening

招聘需求与候选人评估 Skill · **v1.1.0**

将岗位期待、简历和面试记录转化为可验证的招聘判断。适用于支持 Agent Skills 的助手；无需固定的文档平台或付费服务。

## 能做什么

- 撰写或优化JD，明确职责、边界、必备条件和内部筛选标准。
- 设计初试问题，覆盖真实案例、临时问题、假设情境、协作和新技能。
- 评估候选人的能力、业务理解、职责层级、成果、稳定性、动机和招聘条件。
- 根据面试补充更新同一候选人，标明证据、疑点和评分变化。
- 选择聊天、本地文件或已有连接的在线文档交付。

## 安装

从 GitHub Release 下载 `candidate-screening_v1.1.0.zip`，解压得到 `candidate-screening` 文件夹，放入助手支持的技能目录。Codex 通常使用 `~/.codex/skills/candidate-screening`；其他客户端按各自配置安装。已有同名技能时先备份个人修改再替换。

也可以克隆仓库，将仓库内容作为 `candidate-screening` 技能目录使用。技能不需要安装Python或额外依赖；仅在读取特定文件、输出DOCX或连接在线文档时需要环境已有的相应能力。

## 开始使用

首次提供岗位草稿或用人期待、招聘条件和希望输出的内容。评估候选人时提供简历及可选的面试记录。需要保存时指定一次格式与位置；已有确认信息不用每次重复。

示例：

```text
使用 $candidate-screening 优化这份预算主管JD。
岗位以年度预算、月度分析和滚动预测为主。
先给建议，再生成JD及内部筛选标准，保存到我指定的本地目录。
```

```text
使用 $candidate-screening 根据这个JD分析候选人。
关注连续预算周期、本人职责和成果口径。
按H1姓名加AI评分写入已确认的面试记录文档。
```

```text
使用 $candidate-screening 为该岗位设计45分钟初试问题，
包含真实案例、临时数据问题、假设情境及AI/自动化技能，附追问和观察要点。
```

## 输出位置由用户决定

支持聊天输出、本地Markdown以及环境能够处理的其他文件；在线可选钉钉、Notion、Google Docs、Microsoft 365等，但需要用户自己的连接及权限。本技能不附带这些平台的连接器，也不自动安装它们。保存失败会明确报告，不会假称在线写入成功。

## 评估边界

评分用于辅助人类判断。缺少材料标记待验证；薪资差距与能力分开判断。预算岗关注完整周期及次年改进，短任职不自动等于能力差，长任职也不自动等于持续负责预算。

附带市场总监渠道运营及预算主管岗位卡，均为可选起点，用户JD优先。真实岗位资料、候选人信息和私人文档映射保存在用户任务中，不进入公开包。无遥测、无自动调用上报。
